# Shorts Agent · Polza AI

Telegram-бот: тема → сценарий → готовые фотографии → цельная русская озвучка → вертикальный MP4.

## Railway

Репозиторий mfievmkmkm/shortsss, Root Directory /, одна реплика. Команда запуска берётся из Dockerfile.

```env
TELEGRAM_BOT_TOKEN=токен
POLZA_API_KEY=ключ
ALLOWED_USER_IDS=числовой_Telegram_ID
TEXT_MODEL=openai/gpt-4o-mini
VOICE_MODEL=elevenlabs/text-to-speech-multilingual-v2
VOICE=Roger
PEXELS_API_KEY=необязательно
PIXABAY_API_KEY=необязательно
```

Если старые VOICE_MODEL и VOICE уже заданы в Railway, замените их: переменные перекрывают defaults в коде. Стандартные OpenAI-голоса не подходят ElevenLabs.

## Использование

/start или /new → формат → тема. /voice присылает отдельную платную короткую пробу нового голоса.

Один запрос ElevenLabs озвучивает весь рассказ. stability 0.38, similarity_boost 0.75, style 0.35. Посимвольные тайминги Polza задают смену сцен и субтитры по два слова. При отсутствии или несовпадении таймингов сборка останавливается, без скрытого перехода на старый голос. Фактическая стоимость озвучки берётся из usage.cost_rub, если провайдер её вернул; текст и визуальная проверка оплачиваются отдельно.

Все фотографии подбираются ДО оплаты речи. Pexels → Pixabay → Wikimedia Commons. Мультимодальная модель проверяет соответствие каждого кадра сцене; до трёх попыток. Общий поиск по последнему слову, случайные повторы кадров и однотонная заглушка удалены. Если кадр не найден, бот показывает причину. Проверка моделью может ошибаться, особенно в идентификации людей, и не заменяет просмотр человеком.

FFmpeg: 540×960, 24 fps, один поток, чередование приближения и отдаления, крупные субтитры с цветовым акцентом, непрерывная аудиодорожка, нормализация громкости. Разрешение ограничено ради памяти Railway. Кадры монтируются с точностью до кадра, субтитры — по таймингам речи. Ссылки и лицензии приходят отдельным сообщением.

## Практические ограничения

Это документальный формат с готовыми фото. Он не воспроизводит единый иллюстрированный стиль ролика про Пушкина. Для такого результата нужен подготовленный набор иллюстраций; загрузка набора пока не реализована. Музыки, анимации персонажей и фактчекинга внешних источников пока нет. Нельзя считать сгенерированный сценарий исторически проверенным.

Качество и произношение нового голоса нужно оценить через /voice и на реальном ролике. Локальная проверка рендера использовала тестовую аудиодорожку и имитацию ответа Polza; реальные ключи и Railway в ней не использовались.

Очередь в памяти теряется после рестарта. Один Telegram-токен должен использоваться одним polling процессом. Ошибка 409 означает конфликт процессов. Pexels 403/1010 отключает этот источник до рестарта. FFmpeg -9 обычно требует проверить лимит памяти и логи Railway.

Для локального запуска нужны Python 3.12, FFmpeg с libass/drawtext и шрифты DejaVu с кириллицей. Dockerfile устанавливает системные зависимости.
